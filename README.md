# 32bit-RISCV-CPU
A 32 bit cpu using RV32I ISA and a 5 stage pipeline. Plan to test and verify with SV and UVM, RISC-V's official test suite, and synthesize on FPGA to run a game of pong made on bare metal c++ or assembly(not sure yet).

This is built off my original 4 bit CPU, here is that [repo](https://github.com/mohamedzarooq/4-Bit-Verilog-CPU).
